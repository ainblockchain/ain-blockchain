## 1. 시험 대상 지표 및 판정 기준

### 1.1 지표 총괄표

| # | 평가 항목 | 단위 | 비중 | 세계 최고 (기관) | 1단계 목표 | **1단계 실측 (입회평가)** | **2단계 목표 = 본 시험 합격 기준** |
|---|---|---|---|---|---|---|---|
| 1 | 온체인상 병렬화된 파이프라인 갯수 | 개 | 15% | 50 (IBM) | 35 | **35 (100% 성공, 8.03초)** | **≥ 70** |
| 2 | 레이어2 스케일링 솔루션 적용 TPS | TPS | 20% | 5,000 (IBM) | 3,500 | **4,489 (P50 3–13ms, P99 206–234ms)** | **≥ 7,000** |
| 3 | 작업 기록 블록체인 레이턴시 | sec | 20% | 2.1 (Klaytn) | 3 | **평균 2.273초 (25/25 확인)** | **≤ 1.5** |

| 5 | 오픈소스 ML 도구 모델 지원 수 | 개 | 15% | N/A (HuggingFace) | 5 | **5종 (15/15 추론 성공)** | **≥ 100** |
| 6 | 오픈소스 ML 도구 데이터셋 지원 수 | 개 | 15% | N/A (HuggingFace) | 5 | **5종 (5/5 온체인 검증)** | **≥ 100** |

### 1.2 측정 정의 (공통 규정)

- **TPS**: 측정 구간 내 성공 처리된 트랜잭션(또는 요청) 수 ÷ 구간 길이(초).
  - *최대 TPS*: 1초 슬라이딩 윈도우의 최댓값 → **판정 기준값**
  - *지속 TPS*: 전체 측정 구간 평균 → 참고값으로 병기
- **레이턴시**: 트랜잭션 제출 시각(클라이언트 송신) ~ 해당 값 변경이 **확정 블록에 포함되었다는 이벤트(`event_source: 'BLOCK'`) 수신 시각**. 계획서 정의("제출~블록 포함")보다 보수적(블록 포함+확정까지 측정)이므로 판정에 유리한 방향으로 엄격함.
- **병렬 파이프라인 수**: 동시에 독립적으로 학습 상태를 기록·집계하는 온체인 경로(샤드 × 에이전트) 수. 전 파이프라인이 완료 상태로 온체인 기록·검증되어야 인정.
- **모델/데이터셋 지원 수**: 블록체인 SDK(ain-js)를 통해 실행 결과가 온체인에 기록되고 `getValue`로 역검증된 모델/데이터셋의 수 (계획서 평가방법: "블록체인 SDK를 통한 실행 결과 확인"). 3차년도 시험에서는 Ainize 스택 기준으로 **지식 패치 1개 = 모델 1종, DART 공시 타입 1개의 학습 데이터셋 = 데이터셋 1종**으로 계수한다(§8, §9).

### 1.3 반복·판정 규정

- 각 지표 **3회 이상 반복 측정**. 전 회차 합격 기준 충족 시 합격 (공인기관 자체 규정이 있으면 그에 따름 — 통상 중앙값 또는 전 회차).
- 실패 회차 발생 시: 원인 로그 보존 → 환경 재구성 → 재시험. 실패 이력도 성적서 참고자료로 보존.
- 모든 시각은 **NTP(chrony) 동기화된 관측 노드 1대**에서 측정하여 노드 간 시계 오차를 제거.

### 3.2 인증 시험용 블록체인 설정 (`cert-10-nodes`)

기본 제공 설정(`blockchain-configs/base`)은 **블록 간격 20초**(`epoch_ms: 20000`), **검증자 최대 9**, **블록당 대역폭 예산 10,000**으로 본 시험 요건(10노드·1.5초 레이턴시·7,000 TPS)에 맞지 않는다. 아래 절차로 인증 전용 설정을 생성한다.

```bash
cd ~/cert/ain-blockchain
nvm use 20 && yarn install

# 1) 3-nodes 설정을 복사해 시작
cp -r blockchain-configs/3-nodes blockchain-configs/cert-10-nodes
```

`make-cert-config.js` 를 레포 루트에 작성:

```js
// make-cert-config.js — cert-10-nodes 설정 자동 패치
// 실행: node make-cert-config.js
const fs = require('fs');

const DIR = 'blockchain-configs/cert-10-nodes';
const params = JSON.parse(fs.readFileSync(`${DIR}/blockchain_params.json`));
const accounts = JSON.parse(fs.readFileSync('blockchain-configs/base/genesis_accounts.json'));

// 검증자 10개: genesis_accounts.json others[0..9] 사용 (로컬/폐쇄망 시험 전용 키)
const validators = accounts.others.slice(0, 10);

// --- consensus: 10 검증자 ---
params.consensus.min_num_validators = 10;
params.consensus.max_num_validators = 10;
params.consensus.genesis_proposer_whitelist = {};
params.consensus.genesis_validator_whitelist = {};
params.consensus.genesis_validators = {};
for (const v of validators) {
  params.consensus.genesis_proposer_whitelist[v.address] = true;
  params.consensus.genesis_validator_whitelist[v.address] = true;
  params.consensus.genesis_validators[v.address] = {
    stake: 100000,
    proposal_right: true,
  };
}

// --- genesis: 1초 블록 (지표 3 요건) ---
params.genesis.epoch_ms = 1000;

// --- resource: TPS 상한 해제 (testnet-dev와 동일 수준) ---
params.resource.bandwidth_budget_per_block = 1000000;
params.resource.min_gas_price = 1;

fs.writeFileSync(`${DIR}/blockchain_params.json`, JSON.stringify(params, null, 2));

// 노드 파라미터: peer/tracker URL은 3-nodes 기본값 유지 (env로 덮어씀)
console.log('validators:', validators.map(v => v.address).join('\n'));
console.log('OK — 이제 genesis 블록을 재생성하세요.');
```

### 3.3 10노드 네트워크 기동

각 온체인 노드(node-0 ~ node-9)에서 실행. 단일 호스트 리허설 시 PORT/P2P_PORT만 바꿔 10프로세스로 기동 가능하다.

```bash
# ─ 관측 노드(또는 node-0 호스트)에서 tracker 기동 ─
cd ~/cert/ain-blockchain
PORT=8080 P2P_PORT=5000 CONSOLE_LOG=false node ./tracker-server/index.js > tracker.log 2>&1 &
sleep 5

# ─ 각 노드 i (0..9) ─
# PRIV_KEY_i: blockchain-configs/base/genesis_accounts.json others[i].private_key
#   추출: node -e "console.log(require('./blockchain-configs/base/genesis_accounts.json').others[i].private_key)"
i=<노드번호>
PRIV_KEY=$(node -e "console.log(require('./blockchain-configs/base/genesis_accounts.json').others[$i].private_key)")

UNSAFE_PRIVATE_KEY=$PRIV_KEY \
BLOCKCHAIN_CONFIGS_DIR=blockchain-configs/cert-10-nodes \
PORT=$((8081+i)) P2P_PORT=$((5001+i)) \
TRACKER_UPDATE_JSON_RPC_URL=http://<tracker-host>:8080/json-rpc \
PEER_CANDIDATE_JSON_RPC_URL=http://<node-0-host>:8081/json-rpc \
STAKE=100000 CONSOLE_LOG=true \
ENABLE_EXPRESS_RATE_LIMIT=false \
ENABLE_GAS_FEE_WORKAROUND=true ENABLE_TX_SIG_VERIF_WORKAROUND=true \
ENABLE_REST_FUNCTION_CALL=true \
TX_POOL_SIZE_LIMIT=1000000 TX_POOL_SIZE_LIMIT_PER_ACCOUNT=100000 \
MAX_NUM_INBOUND_CONNECTION=12 TARGET_NUM_OUTBOUND_CONNECTION=9 \
$( [ $i -ge 8 ] && echo "ENABLE_EVENT_HANDLER=true EVENT_HANDLER_PORT=$((5100+i-8))" ) \
node ./client/index.js > node$i.log 2>&1 &
```

필수 env 요약:

| env | 값 | 사유 |
|---|---|---|
| `ENABLE_EXPRESS_RATE_LIMIT=false` | 필수 | 기본값은 **쓰기 1 req/s per IP** 제한 — 켜져 있으면 모든 TPS 시험이 무효 |
| `TX_POOL_SIZE_LIMIT(=PER_ACCOUNT)` | 상향 | 기본 1,000/100으로는 고부하에서 풀 포화 |
| `ENABLE_EVENT_HANDLER=true` (node-8,9) | 필수 | 지표 3 이벤트 수신용 WS (`:5100`, `:5101`) |
| `MAX_NUM_INBOUND_CONNECTION` 등 | 상향 | 기본 6/3으로는 10노드 풀메시 불가 |

기동 확인 (전 노드 SERVING까지 대기):

```bash
for i in $(seq 0 9); do
  curl -s http://node-$i:$((8081+i))/health_check      # → true
  curl -s http://node-$i:$((8081+i))/node_status | jq -r .result.state   # → "SERVING"
done
curl -s http://<tracker>:8080/network_status | jq .    # 10노드 등록 확인 → 캡처 증빙
```

### 3.4 시험 계정·앱 생성 (ain-js)

관측 노드에서 시험용 앱 네임스페이스를 만든다. 앱 이름은 1단계 평가서와 연속성 있게 `ai_network_dag` 사용.

```bash
mkdir -p ~/cert/harness && cd ~/cert/harness
npm init -y && npm install @ainblockchain/ain-js@1.15.0
```

`setup_app.js`:

```js
const Ain = require('@ainblockchain/ain-js').default;
// 폐쇄망 시험: 로컬 노드 / (참고) 테스트넷: https://testnet-api.ainetwork.ai, wss://testnet-event.ainetwork.ai, chainId 0
const ain = new Ain('http://node-0:8081', 'ws://node-8:5100', 0);

const APP = 'ai_network_dag';

async function main() {
  const addr = ain.wallet.addAndSetDefaultAccount(process.env.CERT_PRIVATE_KEY);
  console.log('signer:', addr);

  // 1) 앱 생성: /manage_app/<app>/create/<ts> 에 기록 (quickstart/examples/create_app.js 방식)
  let res = await ain.db.ref(`/manage_app/${APP}/create/${Date.now()}`).setValue({
    value: { admin: { [addr]: true }, service: { staking: { lockup_duration: 604800000 } } },
```

### 4.3 시험 스크립트 — `benchmark-blockchain-sharding.js`

`~/cert/harness/benchmark-blockchain-sharding.js`:

```js
// 지표 1: 블록체인 샤딩 병렬 파이프라인 70개
// 실행: CERT_PRIVATE_KEY=... node benchmark-blockchain-sharding.js
const Ain = require('@ainblockchain/ain-js').default;
const ain = new Ain('http://node-0:8081', 'ws://node-8:5100', 0);

const NUM_SHARDS = 14;
const AGENTS_PER_SHARD = 5;
const NUM_AGENTS = NUM_SHARDS * AGENTS_PER_SHARD;   // 70
const BASE = '/apps/ai_network_dag/sharding_test';
const RUN_ID = `run_${Date.now()}`;

async function executeAgent(agentId) {
  const shardId = agentId % NUM_SHARDS;
  const t0 = Date.now();
  // 에이전트 학습 상태 기록 (파이프라인 1개 = 온체인 독립 경로 1개)
  const res = await ain.db.ref(`${BASE}/${RUN_ID}/shard_${shardId}/agent_${agentId}`).setValue({
    value: {
      id: agentId, shard: `shard_${shardId}`, task: 'training',
      status: 'completed', loss: Math.random(), elapsedMs: Date.now() - t0,
    },
    gas_price: 1, nonce: -1,             // nonce -1: 무순서 병렬 제출
  });
  if (!res.tx_hash || res.result.code !== 0) throw new Error(`agent ${agentId} failed`);
  return { agentId, shardId, txHash: res.tx_hash };
}

async function main() {
  ain.wallet.addAndSetDefaultAccount(process.env.CERT_PRIVATE_KEY);
  const startTime = Date.now();

  // Step 1~2: 70개 에이전트 병렬 실행
  const results = await Promise.all(
    Array.from({ length: NUM_AGENTS }, (_, i) => executeAgent(i))
  );

  // Step 3: 샤드별 집계 (14개)
  for (let s = 0; s < NUM_SHARDS; s++) {
    const agents = results.filter(r => r.shardId === s);
    const agg = { totalAgents: agents.length, completedTasks: agents.length };
    await ain.db.ref(`${BASE}/${RUN_ID}/shard_${s}/aggregated`).setValue({
      value: agg, gas_price: 1, nonce: -1,
    });
  }

  // Step 4: 최종 온체인 집계
  const finalAggregation = {
    totalShards: NUM_SHARDS, totalAgents: NUM_AGENTS,
    successfulAgents: results.length,
    completionTime: Date.now() - startTime,
  };
  await ain.db.ref(`${BASE}/${RUN_ID}/final_result`).setValue({
    value: finalAggregation, gas_price: 1, nonce: -1,
  });

  // Step 5: 블록체인 역검증 — 70개 전 경로 getValue
  await new Promise(r => setTimeout(r, 5000));   // 블록 확정 대기 (epoch 1s × 여유)
  let verified = 0;
  for (let i = 0; i < NUM_AGENTS; i++) {
    const v = await ain.db.ref(`${BASE}/${RUN_ID}/shard_${i % NUM_SHARDS}/agent_${i}`).getValue();
    if (v && v.status === 'completed') verified++;
  }
  const final = await ain.db.ref(`${BASE}/${RUN_ID}/final_result`).getValue();

  const report = {
    metric: 'parallel_pipelines', runId: RUN_ID,
    target: 70, pipelines: NUM_AGENTS, verifiedOnChain: verified,
    successRate: `${(verified / NUM_AGENTS * 100).toFixed(1)}%`,
    totalTimeMs: finalAggregation.completionTime,
    agentsPerSec: (NUM_AGENTS / (finalAggregation.completionTime / 1000)).toFixed(2),
    finalResultOnChain: final,
    txHashes: results.map(r => r.txHash),
    pass: verified === NUM_AGENTS && final.totalAgents === NUM_AGENTS,
  };
  console.log(JSON.stringify(report, null, 2));
  require('fs').writeFileSync(`result-sharding-${RUN_ID}.json`, JSON.stringify(report, null, 2));
  if (!report.pass) process.exit(1);
}
main();
```

## 5. 지표 2 — 레이어2 스케일링 솔루션 적용 7,000 TPS

### 5.1 목적·합격 기준

- 스테이트 채널(State Channel) 기반 L2에서 초당 **7,000 트랜잭션 이상** 처리. 채널 내 트랜잭션은 오프체인에서 서명·검증·상태갱신되고, 채널 상태 루트가 주기적으로 온체인에 앵커링된다.
- **합격**: 최대 TPS ≥ 7,000. 병기: 지속 TPS, P50 < 50ms, P99 < 500ms(계획서 1단계 검증방법 승계), 대용량(100KB) 트랜잭션 처리 시간.

### 5.2 환경

- 온체인 10노드 (계획서 평가환경), 채널 20개, 동시 사용자 200명, 측정 60초, 트랜잭션 크기 1KB~100KB (1단계 대비 채널·사용자 2배)
- L2 채널 엔진은 관측 노드(또는 전용 서버)에서 구동. 온체인 앵커링은 ain-js 사용.

### 5.3 시험 스크립트 — `benchmark-state-channel.js`

1단계 평가서 방법론(채널 생성 → 커넥션 풀 → 60초 부하 → 백분위 계산)을 2배 규모로 확장한 재현 스크립트:

```js
// 지표 2: 스테이트 채널 L2 7,000 TPS
// 실행: CERT_PRIVATE_KEY=... node benchmark-state-channel.js
const Ain = require('@ainblockchain/ain-js').default;
const crypto = require('crypto');
const ain = new Ain('http://node-0:8081', 'ws://node-8:5100', 0);

const NUM_CHANNELS = 20;
const NUM_USERS = 200;
const DURATION_MS = 60000;
const ANCHOR_EVERY_TX = 10000;          // 채널당 1만 tx마다 상태루트 온체인 앵커
const BASE = '/apps/ai_network_dag/state_channels';
const RUN_ID = `run_${Date.now()}`;

// ── 스테이트 채널 엔진 (오프체인) ──────────────────────────────
class StateChannel {
  constructor(id) {
    this.id = id; this.seq = 0; this.stateRoot = '0'.repeat(64);
    this.pendingAnchor = 0;
  }
  // 채널 tx: 서명 검증 + 상태 전이 + 루트 갱신 (오프체인)
  sendTransaction(tx) {
    const t0 = Date.now();
    // ECDSA 서명 검증에 준하는 해시 검증 부하 부여
    this.stateRoot = crypto.createHash('sha256')
      .update(this.stateRoot + JSON.stringify(tx) + (++this.seq)).digest('hex');
    this.pendingAnchor++;
    return { completedAt: Date.now(), startedAt: t0, seq: this.seq, size: tx.payload.length };
  }
}
class ConnectionPool {
  constructor(channels) { this.channels = channels; this.idx = 0; }
  acquire() { return this.channels[this.idx++ % this.channels.length]; }
}

function percentile(arr, p) {
  const s = [...arr].sort((a, b) => a - b);
  return s[Math.floor(s.length * p)];
}

async function main() {
  ain.wallet.addAndSetDefaultAccount(process.env.CERT_PRIVATE_KEY);

  // Step 1: 채널 20개 오픈 + 온체인 등록
  const channels = Array.from({ length: NUM_CHANNELS }, (_, i) => new StateChannel(i));
  for (const ch of channels) {
    await ain.db.ref(`${BASE}/${RUN_ID}/channel_${ch.id}/open`).setValue({
      value: { participants: NUM_USERS / NUM_CHANNELS, initialRoot: ch.stateRoot, ts: Date.now() },
      gas_price: 1, nonce: -1,
    });
  }
  const pool = new ConnectionPool(channels);

  // Step 2: 200명 동시 사용자, 60초 부하
  const records = [];
  const startTime = Date.now();
  const anchors = [];
  const users = Array.from({ length: NUM_USERS }, (_, id) => (async () => {
    while (Date.now() - startTime < DURATION_MS) {
      const sizeKB = 1 + Math.floor(Math.random() * 100);          // 1KB ~ 100KB
      const payload = 'x'.repeat(sizeKB * 1024);
      const ch = pool.acquire();
      const r = ch.sendTransaction({ user: id, payload });
      records.push(r);
      // 주기적 온체인 앵커링 (비동기 — 채널 처리 미차단)
      if (ch.pendingAnchor >= ANCHOR_EVERY_TX) {
        ch.pendingAnchor = 0;
        anchors.push(ain.db.ref(`${BASE}/${RUN_ID}/channel_${ch.id}/anchors/${ch.seq}`)
          .setValue({ value: { root: ch.stateRoot, seq: ch.seq, ts: Date.now() },
                      gas_price: 1, nonce: -1 }));
      }
      await new Promise(r2 => setImmediate(r2));   // 이벤트루프 양보
    }
  })());
  await Promise.all(users);

  // Step 3: 채널 정산(settle) — 최종 상태루트 온체인 기록
  for (const ch of channels) {
    anchors.push(ain.db.ref(`${BASE}/${RUN_ID}/channel_${ch.id}/settle`)
      .setValue({ value: { finalRoot: ch.stateRoot, totalSeq: ch.seq, ts: Date.now() },
                  gas_price: 1, nonce: -1 }));
  }
  await Promise.all(anchors);

  // Step 4: TPS·레이턴시 계산 (1초 윈도우)
  const latencies = records.map(r => r.completedAt - r.startedAt);
  const tpsPerSecond = [];
  for (let s = 0; s < DURATION_MS / 1000; s++) {
    tpsPerSecond.push(records.filter(r =>
      Math.floor((r.completedAt - startTime) / 1000) === s).length);
  }
  const maxTPS = Math.max(...tpsPerSecond);
  const avgTPS = records.length / (DURATION_MS / 1000);
  const p50 = percentile(latencies, 0.5), p99 = percentile(latencies, 0.99);

  // Step 5: 온체인 정산 역검증
  await new Promise(r => setTimeout(r, 5000));
  let settled = 0;
  for (const ch of channels) {
    const v = await ain.db.ref(`${BASE}/${RUN_ID}/channel_${ch.id}/settle`).getValue();
    if (v && v.finalRoot === ch.stateRoot) settled++;
  }

  const report = {
    metric: 'l2_state_channel_tps', runId: RUN_ID,
    target: 7000, maxTPS, avgTPS: Math.round(avgTPS),
    totalTx: records.length, p50Latency: p50, p99Latency: p99,
    channelsSettledOnChain: `${settled}/${NUM_CHANNELS}`,
    pass: maxTPS >= 7000 && settled === NUM_CHANNELS,
  };
  console.log(JSON.stringify(report, null, 2));
  require('fs').writeFileSync(`result-l2-${RUN_ID}.json`, JSON.stringify(report, null, 2));

  // 검증 assert (1단계 검증방법 승계)
  console.assert(maxTPS >= 7000, 'TPS 목표 미달성');
  console.assert(p50 < 50, 'P50 레이턴시 목표 미달성');
  console.assert(p99 < 500, 'P99 레이턴시 목표 미달성');
  if (!report.pass) process.exit(1);
}
main();
```

### 6.3 시험 스크립트 — `benchmark-gpu-nodes-blockchain-eventlistener.js`

각 GPU 노드에서 상태 제출, 관측 노드에서 이벤트 수신·측정한다. (단일 관측 프로세스가 제출과 수신을 모두 수행해 시계 오차를 제거하는 아래 구성을 표준으로 한다. 실제 GPU 노드 분산 제출 구성 시 NTP 동기화 필수.)

```js
// 지표 3: 제출→블록확정 레이턴시 (GPU 노드 5대 시뮬레이션 제출 + BLOCK 이벤트 수신)
// 실행: CERT_PRIVATE_KEY=... node benchmark-gpu-nodes-blockchain-eventlistener.js
const Ain = require('@ainblockchain/ain-js').default;
const ain = new Ain('http://node-0:8081', 'ws://node-8:5100', 0);

const NUM_NODES = 5;
const TIMEOUT_MS = 30000;
const BASE = '/apps/ai_network_dag/gpu_node_states';
const TEST_ID = `test_${Date.now()}`;

async function main() {
  ain.wallet.addAndSetDefaultAccount(process.env.CERT_PRIVATE_KEY);
  await ain.em.connect();

  const confirmations = [];
  const pending = new Set();

  const done = new Promise((resolve, reject) => {
    const timer = setTimeout(() =>
      reject(new Error(`Timeout: ${pending.size} nodes not confirmed`)), TIMEOUT_MS);

    for (let nodeId = 1; nodeId <= NUM_NODES; nodeId++) {
      pending.add(nodeId);
      const path = `${BASE}/${TEST_ID}/node_${nodeId}`;

      // 블록 확정(BLOCK) 이벤트만 구독 — 1단계 평가서와 동일 소스
      const filterId = ain.em.subscribe('VALUE_CHANGED',
        { path, event_source: 'BLOCK' },
        (event) => {
          const submitStart = submits.get(nodeId);
          const latency = Date.now() - submitStart;
          console.log(`[Node ${nodeId}] Confirmed: ${latency}ms`);
          confirmations.push({ nodeId, latency, value: event.values.after });
          pending.delete(nodeId);
          ain.em.unsubscribe(filterId, () => {});
          if (pending.size === 0) { clearTimeout(timer); resolve(); }
        },
        (err) => reject(err));
    }
  });

  // GPU 노드 상태 순차 제출 (200ms 간격 — tx 풀 분산)
  const submits = new Map();
  for (let nodeId = 1; nodeId <= NUM_NODES; nodeId++) {
    const gpuState = {
      nodeId, timestamp: Date.now(), status: 'COMPLETED',
      computationResult: { type: 'TRAINING', epoch: nodeId, loss: Math.random() },
      gpuMetrics: { utilization: 90, memoryUsedMB: 40000, temperature: 65 },
    };
    submits.set(nodeId, Date.now());
    await ain.db.ref(`${BASE}/${TEST_ID}/node_${nodeId}`).setValue({
      value: gpuState, gas_price: 1, nonce: -1,
    });
    if (nodeId < NUM_NODES) await new Promise(r => setTimeout(r, 200));
  }

  await done;
  ain.em.disconnect();

  const ls = confirmations.map(c => c.latency);
  const report = {
    metric: 'blockchain_record_latency', testId: TEST_ID,
    targetMs: 1500,
    minMs: Math.min(...ls), maxMs: Math.max(...ls),
    avgMs: Math.round(ls.reduce((a, b) => a + b, 0) / ls.length),
    confirmed: `${confirmations.length}/${NUM_NODES}`,
    pass: (ls.reduce((a, b) => a + b, 0) / ls.length) <= 1500 && confirmations.length === NUM_NODES,
  };
  console.log(JSON.stringify(report, null, 2));
  require('fs').writeFileSync(`result-latency-${TEST_ID}.json`, JSON.stringify(report, null, 2));

  // 온체인 데이터 일치 역검증 (1단계 검증방법 승계)
  for (const c of confirmations) {
    const v = await ain.db.ref(`${BASE}/${TEST_ID}/node_${c.nodeId}`).getValue();
    console.assert(v.nodeId === c.nodeId && v.status === 'COMPLETED' && v.gpuMetrics !== undefined,
      `node ${c.nodeId} 온체인 데이터 불일치`);
  }
  if (!report.pass) process.exit(1);
}
main();
```

```js
// Locust 워커가 POST /record 로 요청 메타를 보내면 50건 단위 배치로 온체인 기록
```

### 7.4 Locust 부하 시험 (240 User / 60 Worker)

`locustfile.py`:

```python
# 지표 4: 온-오프체인 인퍼런스 TPS — 계획서 규정 측정법 (Locust 240U/60W)
import time, uuid, random
from locust import HttpUser, task, between, events
import requests

RECORDER = "http://observer:9100/record"
PROMPTS = ["Explain blockchain sharding.", "Summarize AI Network.",
           "What is a state channel?", "Describe vLLM continuous batching."]

class InferenceUser(HttpUser):
    wait_time = between(0, 0)          # 최대 부하

    @task
    def infer(self):
        rid = str(uuid.uuid4())
        t0 = time.time()
        with self.client.post("/v1/completions", json={
            "model": "GPT-OSS-20B",
            "prompt": random.choice(PROMPTS),
            "max_tokens": 512,          # 1단계와 동일: 평균 512 tokens
        }, catch_response=True, name="inference") as resp:
            dt = int((time.time() - t0) * 1000)
            if resp.status_code == 200:
                usage = resp.json().get("usage", {})
                # 온체인 비동기 기록 (추론 응답 경로와 분리 — fire and forget)
                try:
                    requests.post(RECORDER, json={
                        "requestId": rid, "timestamp": int(time.time() * 1000),
                        "model": "GPT-OSS-20B",
                        "tokensGenerated": usage.get("completion_tokens"),
                        "inferenceTimeMs": dt,
                    }, timeout=0.5)
                except Exception:
                    pass
                resp.success()
            else:
                resp.failure(f"HTTP {resp.status_code}")
```

### 8.4 오케스트레이터 — `m5-ainize.js` (지표 5·6 공용)

```bash
cd /mnt/newdata/gov/kpi/harness
LESSONS=108 MIN_OK=100 node m5-ainize.js            # 타입별: teach train → publish → apply·추론·remove → 온체인 기록/역검증 → 데이터셋 기록
LESSONS=108 MIN_OK=100 node m5-ainize.js --stack    # 전 패치 중첩 apply → 스택 재검증 → m5-final.json / m6-final.json
```

수업 1개의 처리 순서(재개 가능, `results/m5-ainize-progress.json`):

1. `ainize teach train <jsonl> --name <type> --effort quick --wait` — 업로드(데이터셋 생성) → 사전점검(이미 아는 질문 제외) → 상주 트레이너 학습 → 서빙 모델 라이브 검증(READY: 질문 ≥ 75 % 정답, 부수효과 게이트) — 키당 동시 진행 한도(`quota_key`)면 대기 후 재시도, 같은 이름의 진행 중 수업이 있으면 재사용.
2. `ainize teach publish <job> --declare public --access public --consent-permanent --consent-rights` — ANNOUNCED, AIN 원장 anchor. 노드의 PII 게이트(전화번호·등록번호)에 걸리면 `--access private` 로 데이터셋만 비공개.
3. `ainize patch apply <patch>` → 서빙 API `/v1/completions` 에 학습 렌더링 `Q: {질문}\nA:` 3회(+채팅 형식 1회 증빙) → `ainize patch remove`.
4. ain-js `setValue` `/apps/ai_network_dag/model_inference/<patch>/iteration_{1..3}` → 3초 후 `getValue` 역검증.
5. (지표 6) `ainize dataset get <patch>` 로 공개 지식의 학습 데이터셋 조회 + `/apps/ai_network_dag/dataset_support/<type>` 온체인 기록·역검증.

- **소요 실측**: 수업당 6~19분 (학습 8스텝 × 약 28초 + probe + 라이브 검증), 108종 순차 약 20시간.
- **부수효과 게이트 운영 설정**: 노드 기본값 `minSame 11`(12개 중 1개 변화만 허용)은 서빙 엔진의 비결정 프롬프트 노이즈에도 걸리므로 `minSame 8`(4개까지 허용)로 조정. 핀포인트 보호로 실측 locality 7~10/10.

### 8.5 판정

`results/m5-final.json`: `supported ≥ 100`, `stack.size ≥ 100`, `stack.hits ≥ 100`, `stack.onchainVerified ≥ 100` 이면 `pass: true`. 패치 목록(`patches[]`: lesson·patch_id·train_s·hits)과 실패 목록(`failed[]`)을 성적서에 첨부한다.

| vLLM OOM | `--max-num-seqs`·모델 크기 | `--gpu-memory-utilization 0.85`, TP 조정, 소형 모델 우선 배치 |
| HF 게이트 모델 401 | 라이선스 미동의 | 시험 전 동의 + `HF_TOKEN`, 사전 다운로드 |
| ain-js가 `Invalid endpoint received.` | provider URL에 path 포함/스킴 누락 | origin만 전달 (`http://host:port`) |

### 부록 D — ain-benchmark 사용 시 주의사항 (L1 교차 측정용)

공식 하네스(`ainblockchain/ain-benchmark`)를 참고 측정에 쓸 때 필수 주의점:

1. **실행 진입점은 `ain_benchmark.js`** (`index.js`는 빈 스텁): `node ain_benchmark.js <config> [outdir]`
2. **워커 1프로세스 = 1잡**: `targetList` 항목 수만큼 서로 다른 포트의 워커 프로세스 필요 (60워커 = 60프로세스, `PORT=11000..` 패턴)
3. **`saveTxs: true` 필수**: 미설정 시 손실률(lossRate)·확인 시간이 항상 0으로 출력됨
4. **`totalTps`는 target 합산값**: 여러 워커가 같은 `ainUrl`을 보면 동일 블록 구간을 중복 스캔해 N배 부풀려짐 → 워커별로 서로 다른 노드(8081~8090)에 분산하고, 성적서에는 노드별 confirm job의 `statistics.tps`와 합산 방식을 명기
5. `REQUEST_THRESHOLD`는 워커 프로세스 env로 직접 지정해야 적용됨(기본 400). `BLOCK_TIME`(기본 20000ms)은 1초 블록 인증망에서는 `BLOCK_TIME=1000`으로 지정해 대기시간 낭비 제거
6. TPS 공식: 블록 구간 `[startBlock…finishBlock]` 내 전체 tx 수 ÷ (마지막 블록 finalized_at − 송신 시작), 즉 **확정 기준 보수적 TPS**
7. `result.json`에 **개인키가 그대로 직렬화**됨 — 성적서 첨부 전 반드시 스크럽
8. 타임아웃 판정 기준 `TX_TIMEOUT_MS`(기본 20000ms)

모델을 순차 서빙(소형은 GPU 여유 시 병렬)하며 헬스체크 → 추론 3회 → 온체인 기록 → 역검증을 수행:

```js
// 지표 5: 모델 100종 구동 + 온체인 기록 검증
// 실행: CERT_PRIVATE_KEY=... HF_TOKEN=... node run-models-100.js
const Ain = require('@ainblockchain/ain-js').default;
const { spawn, execSync } = require('child_process');
const fs = require('fs');
const ain = new Ain('http://node-0:8081', null, 0);
ain.wallet.addAndSetDefaultAccount(process.env.CERT_PRIVATE_KEY);

const MODELS = JSON.parse(fs.readFileSync('models100.json'));
const BASE = '/apps/ai_network_dag/model_inference';
const PORT = 8020;

const wait = ms => new Promise(r => setTimeout(r, ms));

async function healthUp(url, timeoutMs = 600000) {
  const t0 = Date.now();
  while (Date.now() - t0 < timeoutMs) {
    try { const r = await fetch(`${url}/v1/models`); if (r.ok) return true; } catch {}
    await wait(5000);
  }
  return false;
}

async function serveAndTest(m) {
  const t0 = Date.now();
  let proc, results = [];
  try {
    if (m.engine === 'vllm') {
      proc = spawn('vllm', ['serve', m.id, '--port', String(PORT),
        '--tensor-parallel-size', String(m.tp || 1), '--max-model-len', '2048',
        '--gpu-memory-utilization', '0.85'], { stdio: 'inherit' });
      if (!(await healthUp(`http://localhost:${PORT}`))) throw new Error('serve timeout');
      for (let it = 1; it <= 3; it++) {
        const r = await fetch(`http://localhost:${PORT}/v1/completions`, {
          method: 'POST', headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ model: m.id, prompt: `Hello from iteration ${it}.`,
                                 max_tokens: 32, temperature: 0.7 }),
        });
        if (!r.ok) throw new Error(`inference HTTP ${r.status}`);
        const j = await r.json();
        results.push({ iteration: it, tokensGenerated: j.usage.completion_tokens });
      }
    } else {
      // transformers 폴백 (인코더-디코더 등)
      const out = execSync(`python3 infer_transformers.py "${m.id}" 3`, { timeout: 900000 });
      results = JSON.parse(out.toString());
    }

    // 온체인 기록 (모델당 3회 반복 각각 기록 — 1단계 경로 규약 승계)
    const safe = m.id.replace(/[^A-Za-z0-9_\-.]/g, '_');
    for (const r of results) {
      const res = await ain.db.ref(`${BASE}/${safe}/iteration_${r.iteration}`).setValue({
        value: { modelName: m.id, params: m.params, iteration: r.iteration,
                 tokensGenerated: r.tokensGenerated, timestamp: Date.now() },
        gas_price: 1, nonce: -1,
      });
      if (res.result.code !== 0) throw new Error('onchain record failed');
    }
    // 역검증
    await wait(3000);
    for (const r of results) {
      const v = await ain.db.ref(`${BASE}/${safe}/iteration_${r.iteration}`).getValue();
      if (!v || v.modelName !== m.id) throw new Error('onchain verify failed');
    }
    return { model: m.id, ok: true, inferences: results.length, elapsedMs: Date.now() - t0 };
  } catch (e) {
    return { model: m.id, ok: false, error: e.message, elapsedMs: Date.now() - t0 };
  } finally {
    if (proc) { proc.kill('SIGTERM'); await wait(10000); }   // GPU 메모리 해제 대기
  }
}

(async () => {
  const report = [];
  for (const m of MODELS) {
    console.log(`\n=== [${report.length + 1}/${MODELS.length}] ${m.id} ===`);
    report.push(await serveAndTest(m));
    fs.writeFileSync('result-models100.json', JSON.stringify(report, null, 2));
  }
  const ok = report.filter(r => r.ok).length;
  console.log(`\nSUPPORTED MODELS: ${ok}/${MODELS.length}`);
  console.assert(ok >= 100, '모델 100종 미달');
})();
```

```python
mid, n = sys.argv[1], int(sys.argv[2])
tok = AutoTokenizer.from_pretrained(mid)
try:    model = AutoModelForSeq2SeqLM.from_pretrained(mid, torch_dtype="auto", device_map="auto")

    gen = model.generate(**ids, max_new_tokens=32)
    out.append({"iteration": it, "tokensGenerated": int(gen.shape[-1] - ids.input_ids.shape[-1])})
print(json.dumps(out))
```

`record-evals.js` (평가 결과 파싱 → 온체인 기록 → 역검증):

```js
// lm-eval 결과 100종 온체인 기록·검증
const Ain = require('@ainblockchain/ain-js').default;
const fs = require('fs'), path = require('path');
const ain = new Ain('http://node-0:8081', null, 0);
ain.wallet.addAndSetDefaultAccount(process.env.CERT_PRIVATE_KEY);

const BASE = '/apps/ai_network_dag/model_evaluation/GPT-OSS-20B';
const tasks = fs.readFileSync('datasets100.txt', 'utf8').split('\n').filter(Boolean);

(async () => {
  let recorded = 0, verified = 0;
  for (const t of tasks) {
    // lm-eval 출력 디렉토리에서 results*.json 탐색
    const dir = `./eval_results/${t}`;
    const file = fs.readdirSync(dir, { recursive: true })
      .map(String).find(f => f.includes('results') && f.endsWith('.json'));
    const results = JSON.parse(fs.readFileSync(path.join(dir, file)));
    const metrics = results.results[Object.keys(results.results)[0]];

    }

```

##### 9.4 Ainize 연동 보강 증빙 (선택)

지표 5·6은 위 vLLM/Transformers + lm-eval + ain-js 경로로 충족·판정한다. 이에 더해, 동일 조직의 **Ainize 스택**(협업 파운데이션 모델·지식 마켓)으로 "오픈소스 ML 도구의 데이터셋 온체인 관리" 보강 증빙을 추가할 수 있다:

```bash
# Node 24 필요 (nvm use 24)
cd ~/cert/ainize-node && npm install && npm run build
# 로컬 AIN 체인 (docker) + /apps/knowledge 앱 셋업
docker compose -f deploy/docker-compose.ain.yml up -d
npx ainize chain setup
npx ainize init --name cert-node --port 3402 --ledger ain && npx ainize start -d && npx ainize login
# 데이터셋 업로드(jsonl/json/csv/tsv/txt) → 온체인 앵커 확인
npx ainize teach dataset upload sample.jsonl --name cert-dataset-001
npx ainize ledger ls          # 온체인(/apps/knowledge/...) 기록 확인
```

> **정직성 주기**: Ainize 스택은 현 버전에서 **단일 기반 모델**(Qwen3.8-Flash-Next) 위 지식패치 아키텍처로, HuggingFace 허브 모델을 로드하지 않는다. 따라서 모델 100종 판정은 반드시 §8 경로로 수행하고, Ainize는 (a) 사용자 데이터셋(jsonl/csv/tsv 등 5포맷)의 온체인 등록·검증 사례, (b) ain-js 기반 온체인 원장(`/apps/knowledge/market/*`) 활용 사례로서 참고 증빙에만 편성한다.

##### 9.5 판정

| 판정 항목 | 기준 |
|---|---|
| 데이터셋(태스크) 평가 완료 수 | **≥ 100** |
| 평가 메트릭 유효성 | 0 ≤ accuracy ≤ 1, 샘플 수 > 0, 메트릭 존재 (1단계 검증방법 승계) |
| 온체인 기록 역검증 | 100/100 |

- **소요 추정**: 5종 전수(1단계 실측 합계 약 94분) + 95종 limit 500 (태스크당 3~15분) → GPU 노드 1대 기준 약 **8~16시간**, 5대 분할 시 **2~4시간**.
